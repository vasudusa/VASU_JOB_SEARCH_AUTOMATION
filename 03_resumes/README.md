# Resume Inputs

Place approved resume files here when available.

Required before any real application preparation:

- `Master_Senior_Technical_Project_Manager_Resume.pdf`

Optional variants:

- `Technical_Project_Manager_Resume.pdf`
- `Product_Program_Resume.pdf`
- `International_Implementation_Resume.pdf`

Phase 1 does not fabricate resume-backed facts. If a resume file is missing, the system records an approval/input item and continues in dry-run mode only.
